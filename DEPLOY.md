# Deploying the Barbershop App to Render.com (Free)

The app runs as a single Node.js service on Render: Express serves the API
**and** the built React frontend from the same URL.

---

## Step 1 — Push your code to GitHub

Make sure all your latest changes are pushed to GitHub.

---

## Step 2 — Create a Render account

Go to https://render.com and sign up (free). Connect your GitHub account.

---

## Step 3 — Create a new Web Service

1. Click **New → Web Service**
2. Connect the **felmeta43/barbershop_app** repository
3. Render will detect `render.yaml` automatically — click **Apply**

   If the auto-detect doesn't appear, set these manually:
   - **Build Command**: `npm run install:all && npm run build`
   - **Start Command**: `node server/dist/index.js`
   - **Node version**: 18

---

## Step 4 — Set environment variables

In the Render dashboard → your service → **Environment**, add these secrets.
(Variables marked `sync: false` in `render.yaml` must be filled in manually.)

### Firebase — Required

Get from **Firebase Console → Project Settings → Service Accounts → Generate new private key**

| Variable | Value |
|---|---|
| `FIREBASE_PROJECT_ID` | e.g. `my-barbershop-abc12` |
| `FIREBASE_CLIENT_EMAIL` | e.g. `firebase-adminsdk-xxxxx@my-barbershop-abc12.iam.gserviceaccount.com` |
| `FIREBASE_PRIVATE_KEY` | Paste the full key starting with `-----BEGIN PRIVATE KEY-----` |

### Firebase client-side — Required (baked into the React build)

Get from **Firebase Console → Project Settings → Your apps → Web app config**

| Variable | Value |
|---|---|
| `VITE_FIREBASE_API_KEY` | `AIzaSy...` |
| `VITE_FIREBASE_AUTH_DOMAIN` | `your-project.firebaseapp.com` |
| `VITE_FIREBASE_PROJECT_ID` | same as server |
| `VITE_FIREBASE_MESSAGING_SENDER_ID` | numeric ID |
| `VITE_FIREBASE_APP_ID` | `1:123...` |
| `VITE_FIREBASE_VAPID_KEY` | From **Cloud Messaging → Web Push certificates → Generate key pair** |

### Optional

| Variable | Value |
|---|---|
| `AT_API_KEY` | Africa's Talking API key (for SMS) |
| `AT_USERNAME` | Africa's Talking username |
| `CHAPA_SECRET_KEY` | Chapa secret key (for online payments) |

`JWT_SECRET` is auto-generated by Render — nothing to do.

---

## Step 5 — Deploy

Click **Save Changes** → Render will build and deploy automatically.

Your app URL will be `https://barbershop-app.onrender.com` (or similar).
Share that link with your customers!

---

## Step 6 — Set your Render URL as CLIENT_URL (optional)

If you use Chapa payments, add one more env var so payment callbacks work:

| Variable | Value |
|---|---|
| `CLIENT_URL` | `https://barbershop-app.onrender.com` (your actual Render URL) |

---

## Notes

- **Free tier** spins down after 15 minutes of inactivity — first request may
  take ~30 seconds to wake up. Upgrade to Starter ($7/mo) to keep it always on.
- The database is Firebase Firestore (cloud) — it stays online 24/7 regardless
  of the Render free tier sleeping.
- Admin login defaults: username `admin` / password `admin123` — **change this
  in the admin panel after first login**.
